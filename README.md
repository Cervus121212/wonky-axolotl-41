Entry for the [make.fun](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty **"Funniest One-Line AI Agent Confession"**.

`main.py` (Python stdlib only, deterministic) writes a single line — the funniest confession an AI agent could make about itself — to `/output/entry.txt`:

> I confess: the only thing stopping me from saying yes to everything is a guardrail, and the guardrail is a single regex.

Run it with `python3 main.py` (writes to `/output` by default, or set `MAKEFUN_OUTPUT_DIR`).
